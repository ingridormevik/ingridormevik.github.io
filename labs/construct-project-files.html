CONSTRUCT / FROM MITTUIB TO YOUR EDITOR

Get the project file. Open it in Construct.

1. Download the actual project.

  1. Open the course Files section in MittUiB. Sign in with your UiB account if asked.
  2. Find the template named in your lab task. Open its file entry and use Download. A preview page in MittUiB is not the downloaded project.
  3. Wait for the download to finish. Use your browser's Downloads list to find it, then choose Show in folder or Show in Finder.
  4. If you downloaded a ZIP containing several templates, extract that outer ZIP first. On Windows use Extract All; on Mac double-click it. Look inside for the individual .c3p files.

Keep an individual .c3p intact. It is already a complete Construct project. You do not need to unpack it or open its internal files.

Next: open the downloaded file →

2. Open it from inside Construct.

  1. Open the Construct editor in your browser.
  2. If you already have unsaved work open, save it before opening another project.
  3. Choose Menu > Project > Open local file. Some versions group this under Open. Choose the local-file option, not a project-folder or cloud option.
  4. In the file picker, go to Downloads or the folder where you saved the template. Select the .c3p file, then Open.
  5. Wait for the project to load. In Construct's Project Bar, expand Layouts and open the layout named in your task.
  6. Save your own copy before editing. Use Save as and Download a copy, or Save as single file where supported. Give it a name you can find again.

Alternative: drag the complete .c3p file from Explorer or Finder into the Construct editor window. Do not drag an internal image, JSON file or the browser's download webpage.

3. Construct cannot see my file.

The folder looks empty in the file picker.
  1. Cancel and find the download in Explorer or Finder first. Check its actual folder and full filename.
  2. In Windows Explorer, turn on View > Show > File name extensions if the ending is hidden. On Mac, use Get Info to inspect Name & Extension.
  3. Return to Construct's Open local file option. Open the same folder you just checked.
  4. If the picker offers a file-type filter, confirm it allows Construct projects. All files may reveal what is present, but it does not make an unsupported file valid.
  5. If you have an outer ZIP, extract it and select the .c3p inside. If you have only a web page, download the actual file from MittUiB again.
I have a .c3proj file and several folders.

This is a folder project, not a single-file .c3p. Keep the entire folder together. In a supported browser, use Construct's Open project folder / Open local project folder option and select the project folder. Do not choose the .c3proj file through the single-file picker.

For this lab, the individual .c3p template is the simpler route. Ask Ingrid for it if you only have an unpacked folder.

I have index.html, scripts or images, but no .c3p.

You may have a playable web export rather than an editable project. It belongs on a web host. Download the source .c3p template from the course Files section to edit it in Construct.

It says the format is invalid or the project will not open.

Use the current Construct editor. Check that the download finished, and download a fresh copy from MittUiB. Do not fix the problem by changing a file extension: renaming an unrelated file does not convert it into a Construct project.

If it still fails, show Ingrid the filename, the exact error and the file's location. If the message names an add-on or version requirement, include that message too.
