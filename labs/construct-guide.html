SEE IT / DO IT YOURSELF

One click.
A change.

Find the layout, add two objects and make a click change a line of text. Work in Construct 3 in your browser.

About the screenshots

Real screenshots from the official documentation. The images show the providers' example projects; your project names and content will differ. Open the tool alongside this guide.

One step at a time. Keep the real tool open beside this guide.

STEP 01

Open Construct and create a project.

Open the real Construct editor ↗

On the start page, choose New project. Enter a name you will remember and confirm the dialog. Keep the default settings for this exercise.

Check your screen: Layout 1 and Event sheet 1 are available. The large middle area is where you place objects.

STEP 02

Find the three places you need.

  • 5 / Layout: place text, images and buttons here.
  • 6 / Properties, on the left: edit the selected object's settings.
  • 3 / Tabs, at the top: switch between Layout and Event sheet. The event sheet defines what happens.

Check your screen: Find Layout 1, switch to Event sheet 1, then return to Layout 1.

STEP 03

Add a text object and a button.

  1. Double-click an empty space in Layout 1.
  2. Use Search at the top right of the dialog. Find Text, insert it and place it in the layout.
  3. Select the text object. In Properties, set Text to “A place I know”. Make its box wider if the text is cramped.
  4. Double-click another empty space. Find Button and insert it. Set the button's Text to “See a possible future”.

Check your screen: One Text object and one Button appear in your layout.

Official property references: Text and Button.

STEP 04

Make a click change the text.

  1. Open the Event sheet 1 tab.
  2. Select Add event, then Button → On clicked.
  3. On the same row, select Add action → Text → Set text.
  4. Enter a text string about your possible future, including quotation marks: "Here, we share memories instead of money.". Confirm the dialog.

Check your screen: Your row connects Button / On clicked to Text / Set text.

Official Add condition / Add action instructions ↗.

STEP 05

Run, try and save.

  1. Select Preview. Allow the preview window if the browser asks.
  2. Click your project's button. Check that the text changes.
  3. Return to the editor. Choose Menu → Project → Save as → Download a copy. Keep the .c3p project file in a folder you can find again.

Check your screen: A click produces a visible change and your project is saved. Reopen the saved project to check you kept the right version.

Official saving instructions ↗. Downloads usually go to your Downloads folder unless your browser asks for a location.
