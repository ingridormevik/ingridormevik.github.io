Part 2 · Alinta's map · 1 of 10 · about 3 min

Open the map

SO FARFrom Part 1 you know objects, Properties, behaviors and events.

NOWOpen Alinta's template. It already holds a map of our campus, ready for your places.

DO THIS

  1. Download the Get MappingasNonlinearStorytelling (2).c3p in MittUiB Files ↗

    Then follow the template walkthrough →

    (.c3p).
  2. In Construct, choose Menu › Project › Open local file and pick the file. ①②
  3. In the Project Bar on the right, double-click Layout MapOption1.

YOU SHOULD SEE

The campus map fills the middle. In Properties, Event sheet says Event sheet 1.

Why MapOption1? It is already linked to an event sheet. The other maps say (none): pick one of those and you must set its Event sheet first.

Stuck? Open this first
  • Where is the template? Mitt UiB › Files: MappingasNonlinearStorytelling (2).c3p.
  • It downloaded as a .zip or a folder: unzip it first (right-click › Extract all), then open the .c3p inside. Ignore the __MACOSX folder.
  • Open local file shows nothing: look in Downloads and choose the file that ends in .c3p.

Still stuck after 3 minutes? Ask your neighbour or Ingrid. Everyone gets stuck: that is how you learn this program.

Part 2 · Alinta's map · 3 of 10 · about 6 min

Name your first place

SO FARA locked map you can build on.

NOWA Text object is a label you can put anywhere. Start with one place that means something to you.

DO THIS

  1. Right-click the map and choose Insert new object.
  2. Type Text in Search ①, select Text ②, give it a name such as Library ③, then Insert ④.
  3. Click the map where your place is.
  4. In Properties: write your sentence in Text ①, set Size to 20 ②, tick Bold ③.

YOU SHOULD SEE

Your words on the map. Only part of the sentence shows? The box is too small. Drag its corner handle bigger:

Add two more places the same way. Give each one its own name.

Stuck? Open this first
  • The image editor opened: you double-clicked the map. Close it with ×. Use right-click › Insert new object instead.
  • The map moves when you click: go back one scene and lock it.

Still stuck after 3 minutes? Ask your neighbour or Ingrid. Everyone gets stuck: that is how you learn this program.

Hide a thought

Write the rule: when…

SO FARTouch is in the project.

NOWAn event is a sentence. The left half listens for something. The right half does something.

DO THIS

  1. Open the Event sheet 1 tab and click Add event.
  2. Choose Touch ①, then Next ②.
  3. Choose On tap object ①, then Next ②.
  4. Click <click to choose>, pick Library ①, OK ②, then Done.

YOU DID THIS IN LAB 2

addEventListener("click", …) is the same as On tap object: wait for the visitor, then act.

YOU SHOULD SEE

A new row with Touch on the left: On tap gesture on Library. The dialog said On tap object; the row says On tap gesture on. Same thing.

Stuck? Open this first
  • Library is not in the list: you gave your place another name. Pick that name: it is your place.
  • Chose the wrong object: double-click the condition and choose again.

Still stuck after 3 minutes? Ask your neighbour or Ingrid. Everyone gets stuck: that is how you learn this program.

Play it. Be your own visitor and test it.

Part 2 · Alinta's map · 8 of 10 · about 3 min

Play it

SO FARA finished rule: tap, and the thought appears.

NOWTime to be your own visitor.

DO THIS

  1. Click the small arrow next to ▶ ① and choose Preview layout ②.
  2. Click or tap your place.

YOU SHOULD SEE

The thought appears only after you tap the right place. Tapping anywhere else does nothing: that is the condition doing its job.

Nothing happened?
  • Shows before the tap: select HiddenThought and untick Initially visible.
  • Never shows: the row must name the place you tapped, and the action must name HiddenThought.
  • Wrong map in Preview: use Preview layout, not Preview project.
  • Still nothing: click empty map space and check that Event sheet says Event sheet 1.

Level up A: tap again to hide

SO FARYour map works.

DO THIS

Level up · optional · about 4 minNew: Two actions, one event

Level up B: mark the place as visited

SO FARYour map works.

NOWOne tap can do more than one thing. Make the place remember that someone was here.

DO THIS

  1. On the same row, click Add action again and choose Library.
  2. Type color in Search and choose Set font color.
  3. Write rgbEx(55, 10, 75) ① and choose Done ②. Each number goes from 0 to 100: red, green, blue.

YOU SHOULD SEE

Two actions under one condition. Both run on the same tap, from top to bottom.

Level up C: walk to another map

SO FARYour map works, and now it has a path.

NOWThe template is called Mapping as Nonlinear Networking. Let the visitor choose where to go next.

DO THIS

  1. Drag ExampleArrow from the Project Bar ① onto your map ②.
  2. In the event sheet, Add event: Touch › On tap object › ExampleArrow.
  3. On that new row, Add action › System › Next. Type layout in Search ① and choose Go to layout ② › Next.
  4. Choose Layout MapOption2 and Done. Preview and tap the arrow.

YOU SHOULD SEE

Event 2 reads On tap gesture on ExampleArrow › Go to Layout MapOption2. Your map now has a path.
