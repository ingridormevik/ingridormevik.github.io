Set up your workbench

Open your project folder in VS Code, open your AI chat and keep Live Preview beside it. Save a backup first.

First time? Help me open the tools.
  1. In VS Code choose File → Open Folder. Choose the folder containing index.html.
  2. Open your installed AI extension's chat panel. Need one? Follow the AI setup guide with Ingrid.
  3. Open index.html with Live Preview. This is where you see and try your page.

Use text or voice input if your tool supports it. Give the AI access to your project files, or paste the relevant code into chat.

Nothing changed?

Save the files and reload Preview. Check that you are previewing the same folder the AI edited. Tell the AI exactly what you clicked and what happened, including any error message.

Prefer to code it yourself?

Use the JavaScript beginner guide and make your own changes. AI is optional.

Example: a button that switches between two sentences
const story = document.querySelector("#story");
const button = document.querySelector("#future");
const originalStory = story.textContent;
let showingFuture = false;

function revealStory() {
  showingFuture = !showingFuture;
  if (showingFuture) {
    story.textContent = "Someone else remembers this place differently.";
  } else {
    story.textContent = originalStory;
  }
}

button.addEventListener("click", revealStory);
