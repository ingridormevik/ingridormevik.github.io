LAB 2 / OPTIONAL AI PRACTICE

Make one change with AI in VS Code

Start with your working first-click project. Use AI to change one behaviour, then check the code and the result yourself. You can also make the same change without AI.

1. Choose the change

In this example, the first click shows another perspective. We want the second click to bring the original sentence back.

Open your project folder in VS Code and preview index.html with Live Preview. Copy the folder as a backup before editing.

2. Ask about the code you have

Open your AI chat in VS Code. Include your current story.js and the paragraph and button from index.html. Ask:

My button currently changes the paragraph to another perspective. Change story.js so the next click restores the original sentence. Keep my existing element ids and text. Do not change the HTML or CSS. Show the code you changed and explain how it remembers which sentence is showing.

This request is an example for the first-click project. For your own project, describe its current behaviour and the single change you want.

3. Read the proposed change

Here is one possible answer for our example. Your AI may suggest different code. Compare its answer with the file you already have before accepting or pasting it.

const story = document.querySelector("#story");
const button = document.querySelector("#future");
const originalStory = story.textContent;
let showingFuture = false;

function revealStory() {
  showingFuture = !showingFuture;
  if (showingFuture) {
    story.textContent = "Someone else remembers this place differently.";
  } else {
    story.textContent = originalStory;
  }
}

button.addEventListener("click", revealStory);

The two selectors and the click listener stay the same. originalStory keeps the starting sentence. showingFuture starts as false. Each click flips it, and if chooses which sentence to show.

Check that your own words and ids survived. If the answer changes other files or adds unrelated features, ask for a smaller change.

4. Test in the browser

  1. Save story.js. Reload the preview. The original sentence should appear.
  2. Click once. The other perspective should appear.
  3. Click again. The original sentence should return.
  4. Use Tab to reach the button and press Enter. Check that the same change works.
  5. Reload again. Check the starting sentence.

If it fails, note what you did and what appeared. Check the ids and filename first. Give the AI the observed problem instead of asking it to rebuild the whole page.

5. Keep, adjust or undo

Keep the change if it works and you can explain it. Adjust it if the behaviour or wording needs work. Restore story.js from your backup if you prefer the earlier version.

In your Lab 2 project note, write what you asked for, what changed and what happened when you tested it. Name any AI help you used.

Without AI: type the example yourself, change the sentence to your own words and run the same tests.
