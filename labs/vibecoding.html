LAB 2 / OPTIONAL

Tell the machine what you want.

Vibecoding means describing what you want to build and asking AI to change the code. Write it in your own words, or use voice input if your tool supports it.

Open your project

Open your folder and AI chat in VS Code. Keep a backup and open Live Preview so you can see what changes.

First time using AI here? Open the chat panel for the AI extension you have installed in VS Code. If there is no AI chat yet, use the AI setup guide or ask Ingrid to help you open it.

Keep your project folder open. The chat is where you write your request. Live Preview is where you try the page it changes.

Say what you want

Make this button switch between the two stories each time I click it.

Give the AI access to your current files, or paste the relevant code into the chat.

Type your request in the chat box and send it. If your tool supports voice input, you can say it instead. Use your own language.

If the AI cannot see your files, paste the contents of story.js and the paragraph and button from index.html. Say which filename each piece came from.

If it offers file edits, review and apply the change using your tool's controls. If it only replies with code, ask which file to put it in, then paste it there and save.

Try it. Ask again.

Save and try the button in your preview. Then tell the AI what you want changed next.

The second click still shows the same story. Make it bring the first one back.

That works. Now change the button label to “Another perspective”.

What should happen? First click: the other story appears. Second click: the starting story returns. If Preview still shows the old version, save the file and reload.

You can tell the AI what you see: “I clicked twice, but the starting story did not return.” Keep talking until the result fits what you want.

Keep the result you like. Undo changes you do not want. Add a short note about what you made and any AI help you used.

Want to see one possible code solution?
const story = document.querySelector("#story");
const button = document.querySelector("#future");
const originalStory = story.textContent;
let showingFuture = false;

function revealStory() {
  showingFuture = !showingFuture;
  if (showingFuture) {
    story.textContent = "Someone else remembers this place differently.";
  } else {
    story.textContent = originalStory;
  }
}

button.addEventListener("click", revealStory);
