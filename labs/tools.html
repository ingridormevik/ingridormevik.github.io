Korte handlinger, ekte skjermbilder og lenker til verktøyenes egne veiledninger.

Ekte skjermbilder fra den offisielle dokumentasjonen. Bildene viser leverandørens eksempelprosjekter; dine navn og ditt innhold vil være annerledes. Følg handlingene i verktøyet i en egen fane.

Velg det du skal gjøre nå.

01 / VS CODE + LIVE PREVIEW

Lag og se din første nettside.

Mappe på skrivebordet, HTML-fil og ekte Microsoft-demonstrasjoner.

Åpne guiden →02 / CONSTRUCT 3

Få et klikk til å gjøre noe.

Se hvor Layout, Properties, Event sheet og Preview finnes.

Åpne guiden →03 / GITHUB

Gi nettsiden en lenke.

Finn New repository, Upload files, Settings og Pages.

Åpne guiden →

Ha guiden og verktøyet side om side.

  1. Les steget og se på det ekte skjermbildet.
  2. Åpne verktøyet fra lenken i guiden.
  3. Gjør handlingen selv.
  4. Sjekk resultatet før du går videre.

Les gjerne på mobilen. Utfør øvelsene på datamaskinen. VS Code-ruten bruker det installerte programmet; Construct og GitHub brukes i nettleseren.

Start med et sted, en lyd eller en liten erfaring du kjenner. Bruk teknikken til å gi ditt eget materiale en form. Du trenger ikke generativ KI.
