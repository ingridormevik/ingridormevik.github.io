The everyday loop

  • Pull before you start
  • Commit often, small pieces, real messages
  • Push before you close the laptop

When it goes wrong

Merge conflict

  • Read both versions. Keep what you want. Commit.

Forgot to pull

  • Pull now. If it complains, commit first, then pull.

Committed something huge

  • Stop. Ask before you force anything.

Practice

  • Change one visible thing.
  • Stage it, commit it, push it.
  • Find it on GitHub. That's proof — not “it looks right locally.”

Carry this with you

It just remembers what you did.
