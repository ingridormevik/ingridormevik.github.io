02 / READ ONE RULE

Every CSS rule has the same shape.

This is a real line from your starter. Click each part to see what it does.

:

Selector: body chooses which HTML to style. body means the whole visible page. h1 would mean only your heading, p every paragraph.

Braces { } hold all the instructions for that selector.

Property is what you change: color is the text colour, background is the colour behind it.

Value is how it changes. #f3f0e8 is a warm off-white.

Semicolon ; ends one instruction. Forgetting it is the most common reason CSS silently stops working.

HOW TO READ A HEX CODE

#f3f0e8

A hex code is three pairs: red, green, blue. Each pair goes from 00 (none) to ff (full). #ff0000 is pure red, #000000 black, #ffffff white. #f3f0e8 has almost full red, green and blue, with a little less blue, which is why it feels warm, like paper.

03 / WHY COLOUR SPEAKS

On screens, colour is a language we already know.

You have spent years learning what interface colours mean, without anyone teaching you. Designers use that shared knowledge on purpose. So can you.

Red badge

Notifications, errors, live. Red asks for your attention now. Apps use it because it pulls you back in: colour as part of the attention economy.

Link blue

Early web browsers made links blue, and we still read blue as “click me”. Banks and social platforms lean on blue to look calm and trustworthy.

Dark mode

Night, privacy, a phone in bed. Dark screens feel intimate and late. They can also feel like a terminal, a hacker, a secret.

Soft pastel

The “aesthetic” feed. Pastels signal a mood, an identity and a community. Choosing a palette online is often choosing who you belong with.

Meaning is cultural, not universal. White can mean a wedding in one place and mourning in another. Green can mean nature, money, “go” or a political party. Ask: who is reading this, and what have they learned?

Contrast decides who is included. If text and background are too close, people with low vision, tired eyes or a bright screen outside cannot read your page. Aim for a contrast ratio of at least 4.5 : 1, and never let colour be the only way something is explained.

Nothing changed?
  • Not saved. A dot on the file tab in VS Code means unsaved changes. Press Ctrl/Cmd + S.
  • Missing # or wrong length. A hex code is # plus exactly six characters: #b3122e.
  • Missing ; or }. One missing character can stop the rest of the file. VS Code underlines it in red.
  • Wrong folder. style.css must sit next to index.html, and the <link> line must say href="style.css".

STAGE 1 / UNDERSTAND THE CLICK

Connect a button to a paragraph.

The preview has a paragraph named story and a button named future. Run one line at a time to connect them.

See the HTML these lines refer to
<p id="story">I hear rain at the bus stop.</p>
<button id="future">See a possible future</button>

An id gives an element a name. In a selector, #story means "the element with id story".

  1. 1. Store the new sentence

    const futureText = "In 2040, this stop plays memories left by strangers.";

    const creates a named value. Here, futureText holds the sentence we will show.

  2. 2. Find the paragraph

    const story = document.querySelector("#story");

    document is this webpage. querySelector finds an element. This line finds the paragraph and gives us a reference called story.

  3. 3. Find the button

    const button = document.querySelector("#future");

    The same method finds the button. Neither of these lines changes the page yet.

  4. 4. Connect the click to the change

    button.addEventListener("click", () => { story.textContent = futureText; });

    addEventListener waits for a click. The code inside { } runs after that click. textContent replaces the paragraph's words.

Part 1 · Construct from zero · 11 of 11

What to remember in Construct

Ten rules that solve most problems before they happen.

DO THIS

  1. Save a .c3p every 20 minutes. Download a copy. Construct does not save to your computer by itself.
  2. Preview layout tests the layout you are looking at. Preview project starts at the first layout.
  3. Every layout needs its Event sheet set in Properties, or its rules never run.
  4. Name objects by what they are.
  5. Words go in "quotes". Numbers do not.
  6. Search in every dialog. The lists are long.
  7. Ctrl + Z undoes almost anything.
  8. Double-click a picture opens the image editor. Right-click opens the menu.
  9. Initially visible off means hidden until a rule shows it.
  10. Guests get 25 events per project. Activate Pro (above) for more.

TECHNIQUE 04 / CONDITIONS AND ACTIONS

Gate Engine

Every game is a machine made of rules. In Construct, a rule is an event: a condition, and an action that runs only when the condition is true. Test a rule, wire an event sheet, then design a rule for your own project.

01 / EXPLORE

Find the broken route.

  1. In Construct's Project Bar, expand Layouts and double-click North.
  2. Choose Preview layout. Tap the right arrow to enter East.
  3. Look for a way back. Close Preview and open East in the editor.

Discovery: East's arrow is parked outside the room. A visitor cannot reach it there.

Where are Layouts and Preview?

Expand Layouts in the Project Bar. Use the Preview layout option for the room you are editing, rather than starting the project's first layout.

EXPLORE → NOTICE

Find the reason you are stuck.

Compare East in Preview with East in the editor. Is its arrow inside the room or outside?

02 / REPAIR

Give East an exit.

  1. In East, drag its arrow inside the room, where the visitor can see and tap it.
  2. Click empty space in the layout. Read the Event sheet property and open that sheet from the Project Bar.
  3. Find the tap rule for this arrow. If there is none, choose Add event > Touch > On tap object and select its object type.
  4. On that row, add or edit System > Go to layout. Choose North as the destination.

Try it: Preview East. Tap the arrow. You should arrive in North.

Read an event row in the real editor

When this arrow is tapped → go to North. The condition is on the left. The action is on the right.

If the sheet is shared with North, do not change North's working rule. Use a separate arrow object type for East, or scope the new rule to East. Ask Ingrid to check the rule with you if both arrows currently use the same object type.

REPAIR → TRY

Choose the destination before testing.

Point to the destination in Go to layout. Then Preview and tap. Did the action take you there?

03 / PLAYTEST

Make the round trip.

  1. Preview North. Go to East, return to North, then go out again.
  2. Let a partner try without directions. Can they find both exits?
  3. Move an arrow or add a short Text label if the route is unclear. Test again.
  4. Save a .c3p copy. Use this room connection in your own project.

Working result: a visitor can travel North → East → North without getting stuck.

REMIX → SHARE

Give the journey a purpose.

Add a short Text clue in East. Let a visitor travel there and back. What do they discover along the way?

Another repair? South and West

Repeat the same process for one more room. Decide its destination before creating the action. Test every new connection in both directions.

A room can be a place, a memory or a mood. Choose what the journey means in your project.

TECHNIQUE 05 / TESTING AND REVISION

Test Lab

You know how your project works. Nobody else does. The fastest way to see your work clearly is to watch someone else try it, and to say nothing while they do.

TEST LAB / USER TESTING

  1. Watch≈ 3 minWatch a tester try the page.
  2. Sort≈ 4 minFind the feedback you can act on.
  3. Fix≈ 5 minRepair all three problems.
  4. Retest≈ 3 minWatch the tester again.
  5. Your test≈ 5 minPlan a test for your own project.

STAGE 2 / SORT

Which feedback can you actually act on?

Useful feedback describes what someone did and what they expected. Sort each comment.

  • “It looks good.”

  • “I clicked the title because I thought it would start.”

  • “I didn’t see the start link. It was too pale.”

  • “Nice colours!”

  • “I wasn’t sure what the ☰ icon would do.”

  • “Maybe make it better?”

Sort all six, then check.
