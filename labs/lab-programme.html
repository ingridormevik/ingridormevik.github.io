TECHNIQUE 01 / Structure and style

Change the atmosphere

A paragraph says “The forest remembers.” You change its CSS colour. What should happen?

p { color: #b9ef86; }
1. Make a prediction

JavaScript is needed for the interactive feedback. The explanation is also available below.

2. Test the example

The forest remembers.

Example not run yet.

Why it works

CSS changes presentation. The paragraph’s words belong to the HTML. You can express a mood through styling while keeping the text the same.

Need a hint?

Separate what the page says from how it looks.

Optional extra challenge

Give the same sentence two contrasting moods using only CSS. Ask a partner what each version suggests.

Something is not working?

No visible change? Save the CSS file. Check that index.html links to that file and that your selector matches the element.

3. Use it in your own project

Change one colour or font size in your own project. Before previewing, say what you expect to change. Then explain why that appearance fits your idea.

TECHNIQUE 02 / Events and state

Make the page respond

This button runs the same line each time. What happens on the second click?

story.textContent = "You belong here.";
1. Make a prediction

JavaScript is needed for the interactive feedback. The explanation is also available below.

2. Test the example

Who gets to belong?

Example not run yet.

Why it works

Assignment sets the text to the given value every time. A toggle needs a rule that checks the current state and chooses a different value.

Need a hint?

There is no “otherwise” branch in this line.

Optional extra challenge

Make a button alternate between two messages. Explain the condition that chooses the next message.

Something is not working?

Nothing happens? Check the element’s ID, when the script loads, and the browser console. Confirm that the click listener is attached to the intended button.

3. Use it in your own project

Try your own interaction twice. Describe its starting state, the input and the resulting state. Decide whether a repeated click should repeat, toggle or advance.

TECHNIQUE 03 / Conditions and actions

Open a gate with a rule

The player has two keys. The gate needs at least three. Does this condition pass?

keys >= 3
1. Make a prediction

JavaScript is needed for the interactive feedback. The explanation is also available below.

2. Test the example

Keys: 2 · Gate locked

Example not run yet.

Why it works

With keys = 2, the comparison is false. A condition controls whether its action runs. Once keys reaches 3, the same comparison becomes true.

Need a hint?

Read >= as “greater than or equal to”.

Optional extra challenge

Change the rule so the gate needs exactly three keys. Predict what happens with four, then test it.

Something is not working?

An action happens at the wrong time? Check its condition and event order. Check the initial variable value and whether another event changes it.

3. Use it in your own project

In Construct, identify one condition and its action. Test a case where the condition is false as well as one where it is true.

This practice example is optional and has no score. Your required project milestones and note are in the workbench below.
