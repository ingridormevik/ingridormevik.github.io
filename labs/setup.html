DIN FØRSTE NETTSIDE / OPPSTART

Et sted for
din egen kode.

← Alle verktøyguider · Bildene under er ekte skjermbilder fra Microsoft. Klikk for å forstørre.

Følg sju steg. Til slutt har du en mappe du finner igjen, en HTML-fil og en forhåndsvisning som viser det du lager.

Ha denne guiden åpen på mobilen eller ved siden av VS Code. Selve oppgavene gjør du på en Windows-PC eller Mac. Du trenger ikke KI eller Copilot.

Start med steg 1 ↓

Har du gjort noe av dette før? Kryss av det som allerede virker og fortsett derfra.

Avkryssingen lagres bare i denne nettleseren. Ingen innlevering eller rapport sendes.

STEG 01 / PROGRAMMET

Last ned VS Code.

  1. Åpne code.visualstudio.com ↗.
  2. Velg nedlastingen for Windows eller Mac.
  3. Åpne filen du lastet ned og installer programmet. På Mac: dra Visual Studio Code til Programmer / Applications hvis du blir bedt om det.
  4. Åpne Visual Studio Code fra datamaskinen.

Dette skal du se: VS Code som et eget program, med en velkomstside eller et tomt arbeidsområde.

Trenger jeg å logge inn eller aktivere KI?

Nei. Du kan skrive HTML og bruke Live Preview uten en KI-konto. Hopp over oppsett av Copilot i denne øvelsen.

Neste: lag mappen →

STEG 02 / PROSJEKTETS HJEM

Lag en mappe på skrivebordet.

Gi mappen et navn du husker. For eksempel min-fremtidsverden.

Windows

Gå til skrivebordet. Høyreklikk et tomt sted → Ny → Mappe. Skriv navnet og trykk Enter.

Mac

Åpne Finder → Skrivebord / Desktop. Velg Arkiv / File → Ny mappe / New Folder. Skriv navnet og trykk Enter.

Dette skal du se: en ny mappe på skrivebordet med navnet du valgte.

Denne mappen er prosjektet ditt. Her skal koden, bildene og lydene dine ligge. VS Code er programmet du bruker til å arbeide med filene.

Neste: åpne mappen i VS Code →

STEG 03 / ÅPNE ARBEIDSOMRÅDET

Åpne hele mappen.

  1. Gå tilbake til VS Code.
  2. Velg File → Open Folder… (Fil → Åpne mappe).
  3. Finn Desktop / Skrivebord og velg mappen din.
  4. Klikk Select Folder / Open. Hvis VS Code spør om tillit, bekreft når dette er mappen du selv laget og stoler på.

Dette skal du se: mappenavnet øverst i Explorer, filoversikten til venstre i VS Code.

Jeg ser bare en velkomstside.

Velg View → Explorer. Hvis mappenavnet fortsatt mangler, gjør File → Open Folder… en gang til og velg prosjektmappen.

Neste: lag HTML-filen →

STEG 04 / DIN FØRSTE FIL

Lag index.html.

  1. Høyreklikk mappenavnet i Explorer → New File.
  2. Skriv index.html og trykk Enter. Klikk filen for å åpne den.
  3. Kopier koden nedenfor og lim den inn i den tomme filen.
  4. Lagre med Ctrl+S på Windows eller Cmd+S på Mac.
En liten startside
<!doctype html>
<html lang="no">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Min fremtidsverden</title>
</head>
<body>
  <h1>Et sted jeg kjenner</h1>
  <p>Jeg legger merke til lyden av regn ved busstoppet.</p>
  <details>
    <summary>Hva om dette endrer seg i fremtiden?</summary>
    <p>Hva om vi må betale for å høre lydene fra byen vår?</p>
  </details>
</body>
</html>

Kopierer du på mobilen, får du koden på mobilen. Åpne guiden på datamaskinen for å lime inn i VS Code.

Dette skal du se: filen index.html under prosjektmappen, med koden i redigeringsfeltet.

Skrivebord
└── min-fremtidsverden
    └── index.html
Filen heter index.html.txt.

Høyreklikk filen i VS Code → Rename. Endre hele navnet til index.html. Det skal ende med .html.

Neste: installer Live Preview →

STEG 05 / FORHÅNDSVISNING

Installer Live Preview.

  1. Åpne Extensions fra ikonene til venstre. Du kan også velge View → Extensions.
  2. Søk etter Live Preview.
  3. Velg utvidelsen som har Microsoft som utgiver. Klikk Install.

Se den riktige utvidelsen: Live Preview fra Microsoft ↗

Dette skal du se: Live Preview står som installert. Du kan nå åpne HTML-filen og forhåndsvise den.

Det finnes flere utvidelser med lignende navn.

Se etter navnet Live Preview og utgiveren Microsoft. Den nøyaktige ID-en er ms-vscode.live-server.

Neste: se nettsiden →

STEG 06 / SE DET DU LAGER

Åpne siden i Live Preview.

  1. Gå til Explorer og åpne index.html.
  2. Høyreklikk HTML-filen og velg Show Preview under Live Preview. Du kan også bruke forhåndsvisningsknappen øverst til høyre i redigeringsfeltet.
  3. Se etter teksten Et sted jeg kjenner i forhåndsvisningen.
  4. Klikk Hva om dette endrer seg i fremtiden? Teksten under skal åpne seg.
Vis faktisk handling: åpne forhåndsvisningen

Skjermopptak fra Microsoft. Lukk denne boksen for å skjule animasjonen.

Vis faktisk handling: endre kode og se resultatet

Skjermopptak fra Microsoft Live Preview. Eksempelkoden er deres.

Dette skal du se: en nettside med overskrift, tekst og en linje du kan klikke for å vise mer. Åpne det faktiske resultatet av startkoden ↗.

Forhåndsvisningen er tom eller vises ikke.

Sjekk at filen inneholder koden, heter index.html og er lagret. Sjekk at Live Preview er installert og aktivert. Åpne hele prosjektmappen på nytt om du bare har åpnet en løs fil.

Neste: gjør den til din →

STEG 07 / DIN ERFARING

Bytt ut eksemplet med ditt eget.

  1. Endre teksten mellom <h1> og </h1> til et sted eller en situasjon du kjenner.
  2. Bytt setningen om regn med én detalj du selv har lagt merke til.
  3. Bytt fremtidsspørsmålet og teksten som åpnes med din egen idé.
  4. Lagre. Sjekk at det du endret, vises i Live Preview.

Du er i mål når: siden bruker dine egne ord, teksten kan åpnes, og du vet hvor filen er lagret.

En liten, hverdagslig observasjon er nok. Du bestemmer hva du deler. Dette er en startøvelse, ikke en ferdig eksamensinnlevering.

TA DET VIDERE

Du har et sted å begynne.

Bruk sjekkpunktene over til å finne ut hva som er klart, og hva du trenger hjelp med.

Neste gang: åpne VS Code → File → Open Folder… → velg den samme mappen på skrivebordet. Åpne index.html og start Live Preview igjen.

Etter hvert kan du legge til style.css og en mappe med bilder. Behold alt i prosjektmappen. Live Preview viser siden på datamaskinen din; det publiserer den ikke på nettet.
