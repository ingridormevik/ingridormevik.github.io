SEE IT / DO IT YOURSELF

A home for
your own code.

Seven steps to a folder you can find again, an HTML file and a preview of what you make.

Keep this guide on your phone or beside VS Code. Do the tasks on a Windows computer or Mac. No AI or Copilot is required.

BY THE END OF THIS GUIDE YOU CAN

  • Open a real project folder in VS Code, the editor professional developers use
  • Write a webpage in HTML and watch it update in Live Preview
  • Read every tag in your page and say what it does
Start with step 1 ↓
About the screenshots

Real screenshots from the official documentation. The images show the providers' example projects; your project names and content will differ. Open the tool alongside this guide.

STEP 01

Download VS Code.

  1. Visit code.visualstudio.com ↗.
  2. Choose the download for Windows or Mac.
  3. Open the downloaded file and install the program. On Mac, move Visual Studio Code into Applications if prompted.
  4. Open Visual Studio Code on your computer.

Check your screen: VS Code opens as a separate application, with a welcome page or an empty workspace.

Do I need to sign in or enable AI?

No. You can write HTML and use Live Preview without an AI account. Skip Copilot setup for this exercise. If you want to try AI later, the AI coding guide comes after these steps.

Continue →

STEP 02

Create a folder on your Desktop.

Give it a name you will remember, such as my-future-world.

Windows

Go to your Desktop. Right-click an empty area → New → Folder. Type the name and press Enter.

Mac

Open Finder → Desktop. Choose File → New Folder. Type the name and press Return.

Check your screen: A new folder appears on your Desktop with the name you chose.

This folder is your project. Keep your code, images and sounds here. VS Code is the application you use to work with those files.

Continue →

STEP 03

Open the whole folder.

  1. Return to VS Code.
  2. Choose File → Open Folder….
  3. Find Desktop and select your project folder.
  4. Choose Select Folder on Windows or Open on Mac. If asked about trust, confirm only when this is the folder you created and trust.

Check your screen: Your project folder appears in Explorer, the file panel on the left.

I only see a welcome page.

Choose View → Explorer. If your folder is still missing, use File → Open Folder… again.

STEP 04

Create index.html.

  1. Right-click your folder in Explorer → New File, or select the New File button shown below.
  2. Name the file index.html and open it.
  3. Copy the code below and paste it into this empty file.
  4. Save with Ctrl+S on Windows or Cmd+S on Mac.
A small starting page
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My future world</title>
</head>
<body>
  <h1>A place I know</h1>
  <p>I notice the sound of rain at the bus stop.</p>
  <details>
    <summary>What if this changes in the future?</summary>
    <p>What if we have to pay to hear the sounds of our city?</p>
  </details>
</body>
</html>

Open this guide on your computer to copy into VS Code. Copying on a phone puts the code on that phone.

WHAT DOES THIS CODE MEAN?

  1. <!doctype html>Tells the browser: this is a modern webpage. It is always the first line. HTML intro ↗
  2. <html lang="en"> … </html>Wraps the whole page. lang says the language, so screen readers pronounce it correctly. Elements ↗
  3. <head> … </head>Information about the page that is not shown on it: the tab title, settings and, later, the link to your CSS.
  4. <title>My future world</title>The text in the browser tab.
  5. <body> … </body>Everything people can see on the page goes in here.
  6. <h1>A place I know</h1>The main heading. h1 is the biggest; h2 to h6 get smaller. Headings ↗
  7. <p> … </p>A paragraph of text. Paragraphs ↗
  8. <details><summary> … </summary> … </details>A built-in reveal. The summary is always visible; click it and the rest opens. No JavaScript needed. details ↗

Most tags come in pairs: <p> opens, </p> closes (note the slash). Everything in between is the content.

TRY IT: CHANGE ONE THING

  1. Predict, then change: replace the words inside <h1> with a place you know. Save with Ctrl + S and look at Live Preview.
  2. Add a paragraph: copy the whole <p> … </p> line, paste it underneath and write a new sentence.
  3. Stretch: add a smaller heading with <h2> … </h2> above the question.

STEP 05

Install Live Preview.

  1. Open Extensions from the icons on the left, or choose View → Extensions.
  2. Search for Live Preview.
  3. Select the extension published by Microsoft. Click Install.

Open the official Microsoft Live Preview page ↗

Check your screen: Live Preview is installed and enabled.

Several extensions have similar names.

Choose Live Preview published by Microsoft. Its exact identifier is ms-vscode.live-server.

Continue →

STEP 06

Open your page in Live Preview.

  1. Open index.html in the editor.
  2. Right-click the HTML file and choose the Live Preview Show Preview option, or select the preview button at the top right.
  3. Find the heading A place I know in the preview.
  4. Select What if this changes in the future? to reveal the text below it.

STEP 07

Make the example yours.

  1. Replace the text between <h1> and </h1> with a place or situation you know.
  2. Replace the rain sentence with one detail you have noticed yourself.
  3. Replace the future question and the revealed text with your own idea.
  4. Save. Check that your changes appear in Live Preview.

Check your screen: The page uses your own words, the text can be revealed, and you know where the file is saved.

An ordinary observation is enough. You decide what you share. This is a starting exercise, not a completed final assessment.
