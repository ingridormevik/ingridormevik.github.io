LAB 2 / OPEN VS CODE BESIDE THIS GUIDE

One click.
Your first response.

Make one button change one sentence in your own webpage. Understand it, change it and test it.

HTML puts the paragraph and button on the page. CSS controls their appearance. JavaScript gives the button an action. Today we connect those three things.

A workshop, not a speedrun. You can stop with one working response. No AI or terminal is required.

What do p, button and id mean?

<p> holds a paragraph. <button> creates a button. The words between its opening and closing tags are its label.

id="future" names this particular button so JavaScript can find it. Change the label in VS Code, save and check the preview. Keep the id unchanged.

STEP 2 / TWO FILES, ONE PAGE

Tell the page where its JavaScript lives.

  1. In VS Code's Explorer, create a file called story.js in the same folder as index.html. The ending is .js, not .js.txt.
  2. In index.html, add this line before </head>. If the starter already contains it, keep that one line.
One line inside the head of index.html
<script src="story.js" defer></script>

your-project/
  index.html
  story.js

src="story.js" names the file to load. defer lets the browser finish reading the HTML before it runs that file. The paragraph and button will then be available to find.

VS Code edits and saves the files. The browser in Live Preview runs the JavaScript.

Check: both files sit beside each other in Explorer. Save index.html. An empty story.js is fine for now; the button still has no action.

Why does the script go in head with defer?

<head> contains information about the page. <body> contains its visible content.

src="story.js" points to your JavaScript file. defer lets the browser finish reading the HTML before running that file, so the paragraph and button exist when the code looks for them.

Compare the filename with Explorer in VS Code. A different spelling or folder means the browser cannot load that file.

STEP 3 / FIND, LISTEN, CHANGE

Give your button one job.

Open story.js. Put this code in that file and save. A .js file contains JavaScript, so leave out the HTML <script> tags.

story.js
const story = document.querySelector("#story");
const button = document.querySelector("#future");

function revealStory() {
  story.textContent = "Someone else remembers this place differently.";
}

button.addEventListener("click", revealStory);

Try it now: reload Live Preview if needed, then click Show another perspective. The paragraph should change. The function waits for your click.

READ THE CODE FROM TOP TO BOTTOM

  1. const story = document.querySelector("#story");Find the paragraph. document is the page. querySelector("#story") finds the element whose id is story. const story gives that element a name in our JavaScript. We can change its text while keeping the same reference.
  2. const button = document.querySelector("#future");Find the button. We use the same method, with the button's id. These two lines find things; they do not change what a visitor sees.
  3. function revealStory() { ... }Name an action. A function is a set of instructions we can run. The braces { } enclose this function's instructions. Its name here is revealStory.
  4. story.textContent = "Someone else remembers this place differently.";Change the paragraph's words. textContent is its text. = sets it to the sentence on the right. The quotation marks mean this value is text.
  5. button.addEventListener("click", revealStory);Wait for the click. When this button receives a click, run revealStory. We pass the function's name here, without (), so it can run later.
What are the punctuation marks doing?
  • A dot accesses something on an object: story.textContent means the story element's text.
  • Parentheses hold inputs when a function is called: querySelector("#story").
  • The comma separates the event name and the function in addEventListener.
  • The semicolon ends each statement in this example. Keep the quotes, parentheses and braces paired.
  • revealStory() calls the function now. revealStory in the listener tells it which function to call when a click happens.

Click again. The same sentence stays there because the same instructions run again. Reload the page to return to the initial HTML sentence.

STEP 05

Build the same scene in Construct.

TOOL CHANGE / WEBPAGE → GAME ENGINE

Meet Construct 3 before you open it.

Construct 3 is a game-making application that runs in your browser. You place objects in a scene and give them rules using an event sheet. You can also add JavaScript.

LAYOUT

The scene you arrange: text, buttons, characters and backgrounds.

PROPERTIES

The settings for the selected object: its text, size, position and other options.

EVENT SHEET

The rules: when the button is clicked → change the text.

Why switch? You will rebuild the same interaction in another tool. The idea stays the same; how you find objects and run code changes. Construct objects are not HTML elements, so you will use Construct’s runtime instead of document.querySelector.

  1. Save your working webpage. Keep VS Code open.
  2. Open Construct in a separate browser tab.
  3. Create a project, place your Text and Button, then open its event sheet.

The school’s Pro code is in Alinta’s “Construct 3 Code and more!” announcement. Use the interface guide if a panel is missing.

Open the real Construct editor ↗

  1. Choose New project. Name it My story interaction.
  2. In Layout 1, double-click empty space. Search for Text, insert it and place it inside the visible viewport. Keep its object type name Text.
  3. In Properties, set its text to I hear rain at the bus stop. Make the box wide and tall enough for your sentence.
  4. Insert a Button the same way. Set its displayed text to See a possible future.

Need help finding Layout, Properties or Event sheet? See the labelled interface and basic Construct guide.

Check before continuing: Exactly one Text object named Text and one Button are in the first layout.

STEP 06

Move the idea into a JavaScript action.

In VS Code, create construct-action.js beside your other files. Paste these two lines and save. This file holds the snippet you will copy into Construct.

construct-action.js · paste into a Construct event action
const futureText = "In 2040, this stop plays memories left by strangers.";
runtime.objects.Text.getFirstInstance().text = futureText;

Same idea, different surroundings
WebpageConstruct
HTML paragraph with id="story"Text object named Text
JavaScript click listenerButton → On clicked condition
story.textContent = futureTextruntime.objects.Text.getFirstInstance().text = futureText

The future sentence stays yours. Construct supplies runtime; a plain webpage does not. HTML markup and document.querySelector are not how you address this Construct Text object.

  1. Open Event sheet 1. Select Add event → Button → On clicked.
  2. On that row, open Add… to the right of Add action. Choose Add JavaScript.
  3. Paste only the two lines from construct-action.js into the code editor.

Code reference: Text’s text property. Here getFirstInstance() selects the first Text instance; this exercise deliberately uses only one.

Check before continuing: The JavaScript sits on the Button / On clicked row. If adapting your earlier project, remove its old Set text action so only this action changes the text.

STEP 08

Optional: import a complete .js file.

In VS Code, create main.js in your exercise folder. Save this code:

main.js · Construct startup script
runOnStartup(runtime => {
  runtime.addEventListener("beforeprojectstart", () => {
    runtime.objects.Text.getFirstInstance().text =
      "I hear rain at the bus stop. What could this place become?";
  });
});

  1. In Construct’s Project Bar, right-click the Scripts folder.
  2. Choose Import scripts and select your saved main.js.
  3. Select the imported file. In Properties → Purpose, select Main script. Its name appears bold.
  4. Preview from the first layout. The longer starting sentence should appear before you click. Your existing button action still reveals the future.

The startup callback waits for beforeprojectstart, when objects exist. Only one file can be the main script. Use this in the fresh exercise project; preserve an existing main script in other projects.

Check before continuing: The imported file is under Scripts, has Purpose Main script, and changes the starting text. Importing makes a project copy; later VS Code edits are not automatically linked.

STEP 09

Optional: keep editing the script in VS Code.

For repeated editing, Construct documents a folder workflow. Open the official external-editor walkthrough ↗.

  1. Save your Construct project as a folder project, using the project-folder option under Save as. Choose a new empty folder such as Desktop/my-construct-project. A downloaded .c3p is not a folder project.
  2. Right-click Scripts in Construct’s Project Bar. Enable Auto reload all on preview.
  3. In VS Code, use File → Open Folder… to open that project’s scripts subfolder. Open its main.js, not the earlier source copy.
  4. Edit the starting sentence, save, return to Construct and select Preview.

Keep editing this file in VS Code: auto-reload can overwrite unsaved edits made inside Construct. It updates script files, not snippets pasted into events. If folder saving is unavailable in your browser, use the copy/paste workflow above.

Check before continuing: A saved change in the project’s scripts/main.js appears when you preview in Construct. No manual recopying is needed for that file.

WHEN SOMETHING DOES NOT WORK

Find the missing connection.

The webpage button does nothing.

Save both files. Check that index.html and story.js share a folder, that the script filename matches, and that the ids are story and future. Reload Live Preview and click again. Compare with the downloadable starter.

“runtime is not defined” appears.

You are running Construct code outside Construct. Live Preview runs index.html with story.js. Run construct-action.js as a Construct event action, and main.js as the Construct main script.

Construct cannot find Text, or the text is blank.

Check the object type name is exactly Text, including the capital T, with one instance in the first layout. Its box must be inside the visible viewport, large enough, and have a readable text colour.

The text changes before I click.

The two-line action may be in a standalone script block, which can run every tick. Place it as an action on Button / On clicked. The optional main.js intentionally changes only the starting text.

I changed a VS Code file, but Construct has not changed.

A pasted snippet or imported file is a copy. Paste updated snippets again. For ongoing script-file edits, follow step 9 and edit the file inside the saved Construct project’s scripts folder.

Construct reports a scripting limit.

The Free edition has scripting limits. Keep this exercise small, or use the course’s existing access if supplied. You can also complete the event-sheet-only interaction. See the current official edition comparison.
