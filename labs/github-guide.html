SE HVOR DET ER / GJØR DET SELV

Fra fil.
Til lenke.

Last opp HTML-prosjektet ditt og publiser det med GitHub Pages. Denne ruten bruker GitHub i nettleseren.

Ekte skjermbilder fra den offisielle dokumentasjonen. Bildene viser leverandørens eksempelprosjekter; dine navn og ditt innhold vil være annerledes. Følg handlingene i verktøyet i en egen fane.

STEG 01

Lag ditt eget repository.

Et repository samler prosjektets filer og endringshistorikk på GitHub. Logg inn på din egen konto.

Åpne New repository på GitHub ↗

Gi prosjektet et navn, for eksempel min-fremtidsverden. Velg Public for denne GitHub Pages-øvelsen på gratiskonto, slå på Add a README file og velg Create repository.

Sjekk: du ser ditt eget brukernavn, prosjektets navn og en README. Public betyr at andre kan lese filene. Bruk materiale du vil dele offentlig.

STEG 02

Last opp nettsidefilene.

  1. Velg Add file → Upload files.
  2. Åpne prosjektmappen på datamaskinen. Dra index.html og eventuelle CSS-filer og bildemapper til opplastingsfeltet. Last opp innholdet, slik at index.html ligger på øverste nivå.
  3. Skriv en kort melding om hva du legger til.
  4. Velg å lage en ny branch for endringen, for eksempel min-forste-side, og velg Propose changes.

Sjekk: filene dine er med i endringsforslaget.

STEG 03

Få endringen inn i main.

Fullfør forslaget med Create pull request. Se gjennom filene i forslaget ditt. I ditt eget øvingsrepository: velg Merge pull request → Confirm merge når endringen er riktig.

Se GitHubs faktiske eksempel på pull request og merge ↗

Sjekk: gå til Code og velg main. Nå skal index.html ligge i fillisten på main.

STEG 04

Slå på GitHub Pages.

  1. Velg Settings → Pages i repositoryet ditt.
  2. Under Build and deployment → Source: velg Deploy from a branch.
  3. Under Branch: velg main. Velg mappen /(root). Klikk Save.

Sjekk: main og /(root) er valgt som publiseringskilde.

STEG 05

Åpne den publiserte siden.

Vent på publiseringen. Åpne lenken som vises i Settings → Pages. Den vanlige prosjektadressen er:

https://DITT-BRUKERNAVN.github.io/DITT-PROSJEKT/

Sjekk: lenken viser selve nettsiden, ikke GitHubs filliste. Åpne den også uten å være innlogget, og prøv interaksjonen.

Jeg får 404 eller ser en gammel versjon.

Sjekk at index.html ligger på main i /(root), at navnet er skrevet med små bokstaver, og at publiseringen er ferdig. Se status under Actions i repositoryet. Prøv siden igjen når publiseringen er fullført.

Når du senere endrer filer i VS Code, må de oppdaterte filene også lastes opp til GitHub. Lokal lagring og publisering er to forskjellige handlinger.
