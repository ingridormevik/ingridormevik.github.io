# Friday lab presentation, 30 October 2026

The Halloween entrance, Friday route picker and library lab use the same illustrated room language. The workbench, shelves and connecting passage are drawn as small laboratory rooms. The library route reuses them alongside an observation desk and a desk for bringing an idea back to the creation.

This is a presentation update. Lesson text, link destinations, form attributes, accessible names, timetable, requirements and saved-progress hooks are preserved. No assessment conditions or completion gates were added. The existing route and library scripts still handle navigation.

The five original SVG scenes are decorative and hidden from assistive technology. Selection remains visible through borders as well as the existing pressed/current states. Motion stays on props and respects quiet mode, reduced motion and the accessibility console. Calm layout removes the additional artwork. At narrow widths the Friday controls become horizontal room cards and library navigation becomes a two-column map. Accessibility styles load after the presentation rules.

The presentation is generated by `tools/today_lab_presentation.py`, integrated into the Halloween and standalone library-session builders. `tools/verify_today_lab_presentation.py` compares the actual lesson text, links and controls with the committed version and checks repeatable generation. Existing route, library, timetable, progress and link tests cover their original behavior.

The SVG artwork was rendered and inspected. Full browser visual inspection was unavailable because the browser access host was disconnected. Source and runtime checks do not replace a visual browser review.
